# Demo Guide

To successfully demonstrate SentinelAI:

1. **Start the Platform**: Run `python app.py` (which launches Streamlit).
2. **Navigate**: Open `http://localhost:7860` in your browser.
3. **Select Scenario**: On the left sidebar, select a specific threat (e.g. "Credential Stuffing").
4. **Execute**: Click the **Execute AI Pipeline** button.
5. **Observe Loading**: Point out the sequential architecture execution to the audience.
6. **Executive Overview**: Show how the Top Threat and Average Risk update dynamically.
7. **Deep Investigation**: Navigate to the Deep Investigation tab, select a Critical event, and showcase the SHAP AI Explanations.
