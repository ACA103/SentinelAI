# User Guide (SOC Analysts)

## 1. Executive Security Overview
Provides high-level metrics (Total Events, Critical Threats, Risk Score). Use the Pipeline Comparison table to track how organizational risk changes over time.

## 2. Threat Hunting Queue
Filter events by Risk Level (Critical, High, Moderate, Low). Use the Export CSV function to integrate with external SIEMs.

## 3. Deep Investigation Console
The core of SentinelAI. Select a specific Event ID to view:
* AI Confidence & Anomaly Scores
* SHAP Risk Breakdown (Why the AI flagged it)
* Triggered Deterministic Rules
* Recommended Actions
